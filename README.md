# Nonlinear Dynamics Laboratory

A modern, open-source reconstruction of my 1995 book:
**"Ordnung und Chaos bei nichtlinearen Schwingungen"**
(Order and Chaos in Nonlinear Oscillations)
— Deutsch Verlag, Frankfurt am Main

## About

In 1992–1994 I developed numerical simulations of nonlinear dynamical systems in Pascal and published a book with Harri Deutsch Verlag. The original Pascal source code has been lost, but the mathematics is timeless. This project rebuilds everything in modern Python.

## Repository Structure

```
nonlinear-dynamics-lab/
├── scans/       # Archived high-resolution scans of the original book
├── ocr/         # OCR output (AI-corrected text from scans)
├── markdown/    # Chapters converted to markdown (with LaTeX equations)
├── latex/       # Full LaTeX reconstruction of the book
├── python/      # Python implementations of each simulation
├── notebooks/   # Interactive Jupyter notebooks
├── docs/        # Documentation and educational materials
├── scripts/     # Utility scripts (page splitting, OCR, etc.)
└── tests/       # Automated tests for numerical accuracy
```

## Why This Matters

The mathematics of nonlinear dynamics remains timeless and essential for modern engineering, physics, and AI. This project preserves original scientific work while making it accessible to a new generation through:
- Interactive Python notebooks
- AI-assisted explanations
- Modern visualization
- Open-source educational resources
