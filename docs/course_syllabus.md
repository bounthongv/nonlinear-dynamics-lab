# Course Syllabus
# Numerical Methods for Scientific Computing with Python

**Instructor:** Dr. Bounthong VONGXAYA, Assoc. Prof.
**Level:** Undergraduate / Graduate Engineering
**Duration:** 1 Semester (14 weeks)
**Prerequisites:** Basic calculus, introductory programming
**Tools:** Python, Jupyter Notebooks, Nonlinear Dynamics Lab (custom web app)

---

## Course Description

This course bridges the gap between **theoretical mathematics** and **computational practice**. Students learn numerical methods by implementing them in Python and immediately visualizing the results using interactive simulations.

Built around the *Nonlinear Dynamics Laboratory* — a modern, open-source reconstruction of Dr. Vongxaya's 1995 book *Ordnung und Chaos bei nichtlinearen Schwingungen* — the course shows how simple numerical methods can model complex real-world phenomena from pendulum motion to chaotic systems.

---

## Learning Outcomes

By the end of this course, students will be able to:

1. Implement core numerical methods (Euler, Runge-Kutta) in Python
2. Simulate physical systems using differential equations
3. Visualize and interpret dynamical behavior through phase portraits and time series
4. Identify bifurcations, limit cycles, and chaotic behavior
5. Apply numerical methods to engineering problems
6. Use interactive tools to explore parameter spaces

## Weekly Schedule

### Part I: Foundations (Weeks 1–4)

| Week | Topic | Lab / Simulation | Python Skills |
|---|---|---|---|
| 1 | **Introduction to Scientific Computing** | First steps with Python + NumPy | Variables, arrays, plotting |
| 2 | **Numerical Integration I: Euler Method** | Pendulum simulation (small angle) | Functions, loops, ODE solvers |
| 3 | **Numerical Integration II: Runge-Kutta 4** | Nonlinear pendulum (large angle) | RK4 implementation |
| 4 | **Error Analysis & Stability** | Comparing Euler vs RK4 | Convergence plots, error metrics |

### Part II: Dynamical Systems (Weeks 5–8)

| Week | Topic | Lab / Simulation | Key Concept |
|---|---|---|---|
| 5 | **Fixed Points & Stability** | Logistic map iteration | Attractors, fixed points |
| 6 | **Bifurcations** | Logistic map bifurcation diagram | Period doubling, Feigenbaum |
| 7 | **Limit Cycles** | Van der Pol oscillator | Self-excited oscillations, Hopf bifurcation |
| 8 | **Midterm Project** | Compare two numerical methods on a physical system | Report + code submission |

### Part III: Chaos & Complex Systems (Weeks 9–12)

| Week | Topic | Lab / Simulation | Key Concept |
|---|---|---|---|
| 9 | **Introduction to Chaos** | Lorenz attractor | Deterministic chaos, butterfly effect |
| 10 | **Characterizing Chaos** | Lyapunov exponents | Sensitivity to initial conditions |
| 11 | **Forced Oscillators** | Duffing oscillator | Double-well potential, strange attractors |
| 12 | **Complex Systems** | Double pendulum | Energy conservation, chaos in mechanics |

### Part IV: Applications & Projects (Weeks 13–14)

| Week | Topic | Lab / Simulation |
|---|---|---|
| 13 | **Engineering Applications** | Students select a system to model |
| 14 | **Final Project Presentations** | Interactive demonstration using the Lab |

## Why This Course Matters for Laos

Engineering education in Laos still relies heavily on blackboard mathematics. This course:

- **Modernizes the curriculum** with computational methods
- **Uses free, open-source tools** — no expensive software licenses
- **Builds practical skills** students can use in industry
- **Connects to local infrastructure** — banking, energy, telecom systems all use numerical modeling
- **Prepares students** for graduate studies abroad
